# YatraSutra — Complete SIH Prototype Repository

This is the complete source-code package for the latest cinematic YatraSutra prototype.

## Quick run
Double-click `index.html`.

Or:
1. Install Node.js.
2. Run `npm install`
3. Run `npm start`

## Deploy
The root folder is a static Vercel-ready project.

## Included prototype modules
Spin the Chakra, Draw/Explore Yatra, budget itinerary planner, cinematic Heritage Time Machine, Sonic Heritage, Adopt a Tradition, CultureSwap, Seva Credits, ethical assisted access, offline mesh SOS simulation, Heritage Passport/documentary, bilingual micro-toggle, and sticky module navigation.

See `PROJECT_MANIFEST.md` for every included source file and the boundary between working browser interactions and production integrations.
