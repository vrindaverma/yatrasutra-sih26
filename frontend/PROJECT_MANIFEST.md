## External production systems NOT included because they do not exist in this front-end prototype
There is currently no backend/database/auth/payment/real booking/native Bluetooth mesh/real microphone upload/medical verification/WebAR/production AI service. Those features are represented as prototype interactions only.

## Fonts
Third-party font binaries are deliberately not bundled. The self-contained structured build uses system font fallbacks.
